# Comunidad Activa

Aplicación web para registrar y consultar eventos comunitarios, desarrollada con React, Vite, Node.js y Express. Los registros se almacenan en un archivo JSON.

## Tecnologías

- React y Vite: frontend.
- Node.js y Express: backend.
- JSON: almacenamiento de datos.

## Requisitos

- Node.js y npm.
- Git (para trabajar con el repositorio).

## Instalación

Desde la carpeta raíz del proyecto, instala las dependencias:

cd backend
npm install
cd ../frontend
npm install

## Pruebas

1. Registrar un evento.
2. Comprobar que aparece en la lista.
3. Verificar la validación de los campos obligatorios y del correo electrónico.
4. Reiniciar el backend y comprobar que los datos se conservan.

## Repositorio

El proyecto está organizado en dos carpetas principales: `frontend/` y `backend/`.
